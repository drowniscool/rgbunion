Trigonometric Calculation:
  const radians = (particle.angle * Math.PI) / 180;
  const x = Math.cos(radians) * particle.radius;
  const y = Math.sin(radians) * particle.radius;

CSS Custom Properties:
  --tx: {x}px                    (Full hover distance X)
  --ty: {y}px                    (Full hover distance Y)
  --click-tx: {x * 0.6}px        (60% click distance X)
  --click-ty: {y * 0.6}px        (60% click distance Y)
  --delay: {particle.delay}ms    (Staggered animation delay)

Transform Calculation:
  Initial:  translate(-50%, -50%) scale(0)
  Hover:    translate(calc(-50% + var(--tx)), calc(-50% + var(--ty))) scale(1)
  Click:    translate(calc(-50% + var(--click-tx)), calc(-50% + var(--click-ty))) scale(0.8)
